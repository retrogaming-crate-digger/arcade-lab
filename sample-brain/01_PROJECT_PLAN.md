## 📋 EXECUTIVE SUMMARY

**Sample Brain** is a multimedia collection manager for music producers, VJ artists, and sound designers. It transforms any audio/MIDI/video collection into a production-ready creative tool with DAW integration and live VJ capabilities.

**Core Value Proposition:**
- 🎵 Audio + MIDI + Video management in ONE interface
- 🎛️ Drag & drop export to DAW (Ableton, FL Studio, Logic)
- 🎬 Live VJ performance via Hydra.js
- ⭐ Smart curation (favorites, ratings, crates)
- 🔍 Metadata-driven discovery (BPM, key, mood)

## 💾 CRATE SYSTEM

### What is a Crate?
A **Crate** is a collection that bundles audio + MIDI + video + metadata into shareable project templates.

```javascript
{
  "crateName": "Dark Arcade Production",
  "description": "Glitchy arcade sounds for lo-fi beats",
  "created": "2026-05-18",
  "modified": "2026-05-18",
  "isPublic": false,
  
  "tracks": [
    {
      "romName": "1943kai",
      "audioTrack": "01 Credit.mp3",
      "midiTrack": "01 Credit.mid",
      "videoFile": "1943kai.mp4",
      "bpm": 145,
      "key": "A minor",
      "role": "main_loop",
      "notes": "Use as main synth layer"
    }
  ],
  
  "vjSetup": {
    "primaryVideo": "1943kai.mp4",
    "hydraPreset": "glitch",
    "midiMappings": {
      "cc1": "hydra_scale",
      "cc2": "hydra_rotation"
    }
  },
  
  "exportFormats": {
    "ableton": true,
    "flstudio": true,
    "midi": true,
    "audio": true,
    "video": true
  }
}
```
